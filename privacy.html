Privacy policy

content-pusher · last updated 12 November 2026

1. Who this covers

This policy covers content-pusher, a private software tool operated by a single individual ("the developer"). It is not offered as a service to the public and has no users other than its developer.

2. What data is accessed

When the developer authorises the application through Google's OAuth consent screen, the application receives an OAuth token granting:

  • YouTube Data API — upload (youtube.upload): permission to upload a video to the developer's own channel.
  • YouTube Analytics API — read only (yt-analytics.readonly): permission to read view counts and watch-time statistics for videos on that same channel.

No other Google account data is requested. The application does not read email, contacts, calendar, files, or any other Google service.

3. How data is stored

The OAuth refresh token is stored in a local file on the developer's own computer, protected by the operating system's user account permissions. Video files are stored locally. No database, no cloud storage, and no third-party processor is involved.

4. How data is used

Solely to (a) upload videos the developer has produced, and (b) read the performance statistics of those videos in order to improve subsequent videos. Data is never used for advertising, profiling, training machine-learning models, or any purpose unrelated to publishing on the developer's own channel.

5. Sharing

No data is sold, rented, transferred, or disclosed to any third party. There are no analytics providers, advertising networks, or sub-processors.

6. Google API Services User Data Policy

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Data is used only to provide or improve the user-facing features described above.
  • Data is not transferred to third parties except as necessary to provide those features, as required by law, or as part of a merger or acquisition with prior consent.
  • Data is not used for serving advertising.
  • Data is not used to determine creditworthiness or for lending purposes.
  • No humans read the data, other than the developer reading their own data.

7. Retention and deletion

The OAuth token is retained until revoked. The developer can revoke access at any time at myaccount.google.com/permissions, which immediately invalidates the token, and can delete the local token file. Videos are deleted from local storage at the developer's discretion; videos already uploaded to YouTube are managed through YouTube itself.

8. Security

Access is protected by the developer's own Google account security, including two-step verification. Tokens are never committed to public source control.

9. Children

The application is not directed at children and collects no data from any person other than its developer.

10. Changes

Material changes to this policy will be reflected in the "last updated" date above.
