content-pusher

A private, single-user automation tool for publishing short-form video.

What it is

content-pusher is personal software, not a public product. It renders vertical short videos on the developer's own computer and uploads them to the developer's own YouTube channel through the official YouTube Data API. There are no other users, no sign-up, and no service offered to third parties.

Why it requests Google account access

  • youtube.upload — to upload a finished video to the channel the developer owns.
  • yt-analytics.readonly — to read the view and watch-time statistics of those same uploads, so the format can be improved.

Access is granted by the channel owner through Google's OAuth consent screen and can be revoked at any time at myaccount.google.com/permissions.

Where data goes

Nowhere. The OAuth refresh token is stored in a local file on the developer's machine and is never transmitted to any server other than Google's own APIs. No analytics, no trackers, no third-party services, no advertising.

Privacy

See the privacy policy for the full detail, including how this application complies with the Google API Services User Data Policy.
